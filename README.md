# כיתת ענן — דמו לדשבורד הורים

אב-טיפוס (Demo) לאפליקציית קשר הורה-מורה בעברית, כתחליף לעדכוני וואטסאפ. מציג את מסך הדשבורד כפי שהורה בכיתה רואה אותו: פרטי הכיתה והמורה, הודעות אחרונות, גלריית תמונות כיתתית, צ'אט עדכונים מהמורה, אירועים קרובים עם אישור הגעה, ותורנות הורים שבועית.

יש מתג "תצוגת מורה" בפינה העליונה שמדגים איך המורה מפרסמת הודעה, תמונה או אירוע חדש — והם מופיעים מיידית אצל כל ההורים. כל הנתונים הם נתוני דמו (mock) בזיכרון, ללא שרת אמיתי.

## הרצה מקומית

```bash
npm install
npm run dev
```

## בנייה לפרודקשן

```bash
npm run build
```

## טכנולוגיות

React + TypeScript + Vite + Tailwind CSS 4, בעיצוב RTL עם גופן Heebo.

> זהו דמו בלבד להדגמת רעיון המוצר — אין בו התחברות אמיתית, שמירת נתונים בשרת, או העלאת תמונות אמיתיות.
